# Venta Nodes Purple

A dark-purple Pterodactyl theme starter inspired by the Venta Nodes banner.

## Palette
- Near-black: `#010006`
- Deep violet: `#12013A`
- Electric purple: `#3B049F`
- Neon purple: `#8B3DFF`
- Lavender highlight: `#D9B3F5`

## Files
- `venta-nodes-purple/theme.json` — theme metadata
- `venta-nodes-purple/tokens.css` — color tokens and supplemental CSS

## Compatibility note
This is a theme starter, not a complete redesign of every Pterodactyl page. Theme loading and supported token names depend on your panel version and installed theme framework. Back up your panel and verify the format against the documentation for your exact version. The dashboard mockup is a visual concept; it does not implement new dashboard features.

## Push to GitHub
1. Create an empty repository on GitHub named `venta-nodes-purple`.
2. Extract this ZIP.
3. Open a terminal in the extracted `venta-nodes-purple-github` directory.
4. Run these commands, replacing `YOUR-USERNAME` with your GitHub username:

```bash
git init
git add .
git commit -m "Add Venta Nodes Purple theme starter"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/venta-nodes-purple.git
git push -u origin main
```

If authentication is requested, sign in with Git Credential Manager or run `gh auth login`. Never place a GitHub password or token directly in the source files.
